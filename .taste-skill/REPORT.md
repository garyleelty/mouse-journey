## 5. Electron 回归

本环境沙箱会拦截 Electron 自带沙箱（`sandbox initialization failed` / GPU process 不可用），**无法在代理环境里给真机窗口截图**——这是环境限制，不是应用缺陷。改用两层回归：

1. **渲染层**：harness 直接加载 `src/renderer/` 真实文件（CSS/JS/HTML 原样，仅路径改写 + `window.api` mock），五个页面全部 0 FAIL 0 WARN 即在真实渲染代码上量得。
2. **主进程**：`npm run smoke`（stub 掉 electron，Node 直跑真实模块）——store 原子写与重载往返、tracker 40 tick（14.0 cm / 1 次连续移动 / 39 个轨迹点 / 计次与抽稀逻辑）、calibration（24″ 1080p → 0.02767 cm/点、横扫 53.1 cm、PPI 91.8、manual 模式旁路）、achievements（12000 m → 公交车）、journey（随机线 640 km、5 个景点、下一站西安）全部通过。

## 7. 第二轮：收掉评委点名的三件事

评委打分（§6）点名的三个问题，这一轮全部处理：

| 问题 | 根因 | 修法 |
| --- | --- | --- |
| 地图卡左右各约 12% 白边 | 中国轮廓 1.39:1 塞进 1.7:1 的卡，投影按短边适配 | 新增 `NEIGHBOR_RINGS`（蒙古 / 西伯利亚 / 朝鲜半岛 / 日本 / 中南半岛 / 南亚 / 琉球，示意级简化轮廓）+ `REGION_BBOX`（72.5–146°E × 17.5–54.5°N，约 1.6:1，与卡同宽高比）；周边陆地用更浅的底色画在中国轮廓**之下**，中国仍是视觉主体。附带收益：中国轮廓有了地理参照 |
| 设置页翻页较长（矮窗首屏只见约两节） | 五个 section 全部是「450px 标签列 + 面板」整行 | 两层结构：距离校准保留整行（它是需要解释的英雄节）；采样 / 悬浮窗进两栏卡片（高度天然接近，stretch 后底部齐平）；健康提醒 / 通用各占整行（内部字段改多列）。行距压缩（32→24、面板 gap 16→14、标签列 450→400）。整页 2.6 → 2.1 屏，首屏见校准 + 采样 |
| 统计明细表首屏看不全 | 明细表固定展示全部 23 天，与顶部周期选择无关 | 明细表跟随所选周期（本周 6 行 / 近 14 天 14 行…），封顶 10 行 + "展开全部 N 天"；未来空白天（如本周的周日）只进图表（诚实 0 柱），不进明细 |

过程中踩到并修掉的检测项：

- `ragged-row`：两栏卡片底部差 268/213px → 拉伸（`align-items` 默认 stretch + 面板 `flex:1`）后底部齐平，但短卡内部撑出 284px 空带触发 `panel-void` → 最终按"内容高度配对"重排（采样 272px ↔ 悬浮窗 254px 同行；健康 / 通用整行不参与配对）。
- `overflow @768px`：长路径文本把 grid item 撑宽 → `.kv b { min-width: 0 }` + `grid-template-columns: minmax(0,1fr)`。
- `edge-text @390px`：存档信息三列栅格在 390px 挤压日期贴边 → 三列栅栅加 `min-width: 900px` 门槛。

**顺带完成的小功能**：悬浮窗"显示路线进度（虚线）"开关（store 里早有 `showRoute` 默认值但无 UI，本轮补上并接通 float 渲染）；设置页「通用」卡新增存储信息（数据目录 / 存档大小 / 上次校准，由 `buildState` 快照提供 `dataDir` / `storeBytes`）。

**门禁复跑**：inspect 五页 × 三视口 0 FAIL 0 WARN；lint 三文件 0 FAIL 0 WARN；`npm run smoke` 新增 ipc 快照用例（`buildState` 全量状态：geo context/bbox、存储信息、成就数）后全过。

## 8. 第三轮：第一人称「在路上」视角

需求：不要平面俯视图，要"身临其境、在路上的感觉"（类似街景）。

**实现**（`src/renderer/js/scenery.js`，纯 Canvas 2D 伪 3D）：

- 镜头贴在路面上往前看：透视投影（焦距 250px·m、视高 1.55 m、可视纵深 420 m），地平线 + 远山 + 城市剪影（接近下一站 24 km 内渐显）+ 分层实色天空/地面（**无渐变**）；
- **道路弯曲来自真实数据**：沿路线逐深度采样 `Geo.pointAtKm` 的走向角，积分出每个纵深处的路心横向偏移——路怎么弯完全由真实路线几何决定；
- 路肩景物（电线杆 / 树 / 里程碑桩 / 景点指示牌）按确定性伪随机放在真实里程位置上，随真实行程由远及近；里程碑桩写路线累计 km；
- **尺度即语义**：1 真实米 = 1 路线公里（kmPerMeter=1）= 1000 场景米——画面只随真实鼠标里程前进，停手即静止（HUD 显示由两次状态快照算出的真实鼠标速度），没有任何假动画；
- 唯一数据色 `#1d5fbf` 给路面中心线（= 你走过的行程），色预算不超；
- 今日页：主卡「路上」+ 左下 HUD（下一站 / 下一景点 / 当前速度）+ 右上「全国位置」小地图（俯视地图降为定位辅助）；悬浮窗默认同为路上视角，标题栏按钮可切回地图。

**门禁**：inspect 五页 × 三视口 0 FAIL 0 WARN（连跑两轮确认稳定）；lint 三文件 0/0；smoke 全过。

**过程中修掉的检测项**：① 侧栏坐骑小卡与行程卡被判定同排（ragged-row @768）→ 按 open-plane 规范去掉侧栏卡片化（无边框无底色）；② 设置页 `below-fold`（2/5 块在首屏，且临界抖动）→ 真因是 HTML 里健康提醒（整行）插在采样与悬浮窗之间，grid 稀疏排布把两栏行的右列全部空置——重排为 采样+悬浮窗 同行、健康/通用整行，并压缩行距，首屏稳定 3–4 块（≥0.6）。
